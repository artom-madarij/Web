Вимоги:
● Використовувати семантичні теги (<header>, <nav>, <ul>, <footer> тощо)
там, де це потрібно.
● Усі шрифти, колірна палітра, розміри елементів повинні суворо відповідати
дизайну.
● Ідеальна піксельна точність не потрібна, АЛЕ ваш сайт повинен візуально
відповідати макету (тобто якщо елемент по центру в дизайні, він повинен
виглядати по центру й на сайті).
● Усі назви класів не повинні бути беззмістовними (наприклад, class="myClass")
і повинні дотримуватися єдиного стилю іменування, бажано BEM,
але ви можете придумати свій (головне — послідовність).
● Базова кросбраузерна підтримка (сайт має правильно відображатися
в останніх версіях сучасних браузерів: Chrome, Safari, Edge).
● Поки що адаптивність не потрібна.
